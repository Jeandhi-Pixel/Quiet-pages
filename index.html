KEEP YOUR WORDS SAFE

Backup & privacy

▤

Automatic encrypted folder backups

Choose a folder outside Chrome's private storage. While Quiet Pages is open and access is granted, it automatically updates one encrypted backup file per active hour after you stop typing. Previous hours' files stay in the folder.

Checking folder backups…

Your existing entries stay private, even inside backup files.

An on-phone backup does not protect against a lost or damaged phone. Copy these encrypted files to another device or a cloud-synced folder. Chrome may request access again after restarting; backups cannot run while the app is completely closed.

◷

Automatic local restore points

Quiet Pages stores periodic encrypted historical copies in its dedicated IndexedDB database. Select a point to recover older entries after a mistake.

Checking restore points…

Local restore points are not independent backups: clearing Chrome site data also erases them. An older restore point may require the password used when it was created.

↓

Export an encrypted backup

Download all your entries in an encrypted file. You will need your journal password to restore it.

↑

Restore an encrypted backup

Restore a backup file made by Quiet Pages. This will replace the journal currently on this device.

Good to know

Entries are encrypted using AES-GCM and stored in a dedicated browser IndexedDB database. Nothing is uploaded to GitHub or our servers. Automatic folder backups are encrypted files written only to your chosen folder while access is allowed. Local restore points are erased along with browser site data; external files may remain. Back up outside your phone for loss protection. Your password cannot be reset.
